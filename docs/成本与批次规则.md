# 成本与批次实施规则

用户于2026年10月31日确认。此文件记录实施要求，不表示以下功能已经全部生效。

## 成本

采用移动加权平均成本。每次有明确成本的入库后，以入库前库存价值加本次入库价值除以入库后数量，确定后续出库的平均成本。出库保存当时成本快照，不能用商品当前成本价重算历史毛利。数量清零时库存价值也必须清零，舍入尾差随最后一笔出库处理。

历史库存需要录入可核实的期初成本，缺失成本明确标记未初始化，不得当作零成本计算毛利。退货应关联原收发记录和成本快照，调拨保留来源成本。低单价商品不能将单位成本简单舍入为两位小数，计算精度与最终金额展示应分开处理。

## 商品开关

批次管理按商品设置，默认不自动为全部商品开启。有效期管理也按商品设置；有保质期的商品启用有效期管理时，必须同时启用批次管理。

## 入库与出库

启用批次的商品入库必须登记真实批次号。仅启用有效期管理的商品必须填写生产日期和有效期；无保质期商品不强制填写日期。校验日期合法性、生产日期不晚于有效期，并保存批次资料与数量。

普通销售出库禁止使用过期批次，管理员也不能通过普通销售入口绕过。过期库存应通过报损等独立、有原因和审批留痕的业务处理。批次数量、库存数量、预占数量及批次流水应在同一事务内更新。

已有库存不能自动分配虚构生产批次或日期；应先执行受控的期初批次分配。商品切换管理方式时，须核对已有库存及预占，不能直接关闭开关导致批次与库存脱节。

## 验收要求

覆盖开关组合、真实历史资料录入、普通商品与批次商品收发、过期销售拦截、报损、退货与调拨、并发批次预占、失败整单回滚；检查批次数量合计与库存一致，成本价值与成本流水一致，历史毛利不随商品资料变更。

## 当前状态

现有系统的分批收发单号属于业务执行批次，不等同于上述商品生产批次。商品批次、效期和移动平均成本规则仍需完成实现与验证，不能把已存在的分批收发功能当作全部验收通过。
