# 供应商、客户导入导出

管理员可在供应商、客户列表下载 CSV 模板、导入资料、导出全部资料（不受当前名称搜索条件限制）。CSV 支持 UTF-8 或 GB18030，最多5MB、5000条数据。

名称必填，联系人、电话、邮箱、地址、状态、备注可选；支持中英文表头。状态为1或0，留空默认启用。按名称忽略首尾空格及英文大小写去重，跳过已有资料，不覆盖原记录；同一文件内重复行和重复上传也会跳过。不同名称即使电话相同仍保留，避免合并同集团不同公司。

合法行新增，非法行显示行号及原因；CSV 结构错误整批拒绝，数据库异常整批回滚。结果最多展示100条跳过/失败说明。导入使用同类锁串行处理，防止两个上传请求互相插入重名资料。原数据库中的历史重复资料不会自动删除。

部署已有数据库前执行 `python3 db/migrate_master_import.py`；容器部署方式参见 deploy/README.md。集成验证脚本：`test/verify_partner_import.py`。
